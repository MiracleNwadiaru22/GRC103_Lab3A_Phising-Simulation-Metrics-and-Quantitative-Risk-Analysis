## Project Overview
This project presents a quantitative risk assessment of three phishing simulation campaigns conducted to evaluate employee susceptibility to phishing attacks. It analyses campaign performance, credential submission rates, potential financial exposure, and recommended security controls.

## Objectives
- Evaluate employee responses to different phishing scenarios.
- Calculate phishing metrics, including open rates, click-through rates, and credential submission rates.
- Estimate potential financial exposure using risk assumptions.
- Apply statistical analysis and confidence intervals.
- Recommend security controls to reduce phishing-related risks.

## Key Findings

| Campaign | Scenario | Credential Submission Rate |
|---|---|---:|
| Campaign A | HR Bonus | 18% |
| Campaign B | IT Password Reset | 30% |
| Campaign C | CEO Urgent Document Review | 15% |

**Key Observation:** Campaign B recorded the highest credential submission rate (30%), making it the highest-priority area for risk mitigation.

## Recommended Security Controls
1. Multi-Factor Authentication (MFA).
2. Employee security awareness training.
3. Advanced email filtering.
4. Improved password-reset verification procedures.
5. Continuous security monitoring and recurring phishing simulations.
